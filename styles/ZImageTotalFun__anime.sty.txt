>## HOW TO WRITE A STYLE TEMPLATE
>##    Focus exclusively on visual aesthetics, atmospheric mood, and technical
>##    characteristics (e.g., lighting, texture, lens, weather, and sensory details).
>##    Avoid referencing specific subjects, objects, or characters, as these are
>##    supplied by the user via the {$@} placeholder. Treat the template as a
>##    "lens" or "filter": it dictates how the scene looks and feels, not what
>##    is explicitly happening within it.
>##
>## TEMPLATE DEFINITION
>##    Each new visual style must begin with a line prefixed by ">>>"
>##    followed by the style name. Example: ">>> Landscape Photo"
>##
>## TEMPLATE FORMAT
>##    Every line following the style name represents the prompt used
>##    when that style is selected. The following variables are processed:
>##
>##    {$@} : Replaced by the user's input prompt.
>##
>##    {$IFPAL X | Y} :
>##         Conditional logic for color palettes.
>##         - If a color palette is active, the text before '|' (X) is used.
>##         - If no palette is selected, the text after '|' (Y) is used.
>##         - Within 'X', reference palette colors using $1, $2, $3, and $4.
>##         - Los $1, $2, $3, $4 estan ordenados de mas luminoso $1 a mas oscuro $4
>##         - $5 is an optional highlight color (available solo en algunas palettes).
>##
>##    {$**<cheat-code> X | Y} :
>##         Quick Modifier System
>##         - <cheat-code> consists of one or more characters from: @, *, #, +, -
>##         - If the user's prompt begins with "**<cheat-code>" (e.g., "**@@"), 
>##           the text 'X' is applied.
>##         - If no matching prefix is found, the text 'Y' is applied.
>##
>##    In this file, the following cheat-codes are used:
>##      "@@" : Spicy Impact Booster (enhances sensual and provocative tones)
>##      "##" : Original Framing & Perspective (dutch tilt, dynamic angles)
>##
